📚 Lý thuyết thuật toán Shell Sort


            
Định nghĩa

            

                Shell Sort là một thuật toán sắp xếp so sánh được phát triển bởi Donald Shell vào năm
                1959.
                Đây là một cải tiến của thuật toán Insertion Sort, cho phép trao đổi các phần tử ở xa nhau.
            


            
💡 Ý tưởng cốt lõi (Intuition)

            

                Điểm yếu của Insertion Sort là khi một phần tử nhỏ nằm ở cuối mảng, nó phải
                "bước" từng bước một về đầu mảng, gây ra nhiều phép hoán đổi.
            

            

                Shell Sort giải quyết vấn đề này bằng cách:
            

            
    
                
  1. Chia mảng thành các "sub-array" dựa trên gap
    2. 
                
  2. Sắp xếp từng sub-array bằng Insertion Sort
    3. 
                
  3. Giảm gap và lặp lại cho đến gap = 1
    4. 
                
  4. Khi gap = 1, mảng đã gần như được sắp xếp, Insertion Sort chạy rất nhanh
    5. 
            


            
🔍 Vì sao giảm khoảng cách (gap) giúp tăng tốc?

            

                Bước 1 (Gap lớn): Di chuyển các phần tử nhỏ về gần vị trí đúng nhanh chóng,
                mỗi lần so sánh di chuyển phần tử xa hơn.
            

            

                Bước 2 (Gap nhỏ dần): Tinh chỉnh vị trí các phần tử với độ chính xác cao hơn.
            

            

                Bước cuối (Gap = 1): Mảng đã "gần đúng" (almost sorted), Insertion Sort
                chỉ cần vài phép so sánh và hoán đổi để hoàn thành.
            


            
⏱️ Độ phức tạp thời gian

            

                

                    Trường hợp
                    Độ phức tạp
                    Ghi chú
                

                

                    Best Case
                    O(n log n)
                    Mảng đã sắp xếp hoặc gần sắp xếp
                

                

                    Average Case
                    O(n^1.3) - O(n^1.5)
                    Phụ thuộc vào gap sequence
                

                

                    Worst Case
                    O(n²)
                    Shell's original sequence
                

            

            

                * Với gap sequence tốt như Ciura, độ phức tạp trung bình là O(n^1.3)
            


            
💾 Độ phức tạp không gian & Tính ổn định

            
    
                
  • Space Complexity: O(1) - Sắp xếp tại chỗ (in-place)
    • 
                
  • Stability: Không ổn định (Unstable) - Các phần tử bằng nhau có thể đổi vị trí tương
                    đối
    • 
            


            
🔢 Các Gap Sequence nổi tiếng

            
    
                
  • Shell Original: n/2, n/4, ..., 1 - O(n²)
    • 
                
  • Hibbard: 2^k - 1 - O(n^1.5)
    • 
                
  • Knuth: (3^k - 1)/2 - O(n^1.5) ⭐ Đang dùng
    • 
                
  • Ciura: 1, 4, 10, 23, 57, ... - ~O(n^1.3)
    • 
            


            
📝 Pseudocode chi tiết

            

                
procedure shellSort(array, n)
    // Khởi tạo gap (thường là n/2)
    gap = n / 2

    // Giảm gap cho đến khi gap = 0
    while gap > 0 do
        // Thực hiện insertion sort với gap hiện tại
        for i = gap to n-1 do
            // Lưu phần tử hiện tại
            temp = array[i]
            j = i

            // Dịch chuyển các phần tử cách gap đã sắp xếp
            while j >= gap and array[j - gap] > temp do
                array[j] = array[j - gap]
                j = j - gap
            end while

            // Đặt temp vào vị trí đúng
            array[j] = temp
        end for

        // Giảm gap
        gap = gap / 2
    end while
end procedure

            

        


        
        

            
📜 Lịch sử thuật toán Shell Sort


            
👤 Donald L. Shell (1959)

            

                Shell Sort được phát minh bởi Donald L. Shell vào năm 1959 và
                được công bố trong bài báo "A High-Speed Sorting Procedure" trên tạp chí
                Communications of the ACM.
            

            

                Đây là một trong những thuật toán sắp xếp đầu tiên vượt qua rào cản O(n²) của
                các thuật toán đơn giản như Bubble Sort và Insertion Sort.
            


            
🔢 Timeline các Gap Sequence


            

                
1. Shell's Original Sequence (1959)

                
Công thức: gap = n/2, n/4, n/8, ..., 1

                
Độ phức tạp: O(n²) worst case

                
Ưu điểm: Đơn giản, dễ cài đặt

                
Nhược điểm: Không hiệu quả, vẫn có thể đạt O(n²)

            


            

                
2. Hibbard Sequence (1963)

                
Công thức: 2^k - 1 (1, 3, 7, 15, 31, 63, ...)

                
Độ phức tạp: O(n^1.5) worst case

                
Ưu điểm: Cải thiện đáng kể so với original

                
Nhược điểm: Vẫn chưa tối ưu cho thực tế

            


            

                
3. Knuth Sequence (1973)

                
Công thức: (3^k - 1)/2 (1, 4, 13, 40, 121, ...)

                
Độ phức tạp: O(n^1.5) worst case

                
Ưu điểm: Hiệu quả trong thực tế, dễ tính toán

                
Nhược điểm: Không phải tối ưu nhất

            


            

                
4. Ciura Sequence (2001) ⭐ Khuyên dùng

                
Dãy số: 1, 4, 10, 23, 57, 132, 301, 701, 1750, ...

                
Độ phức tạp: ~O(n^1.3) empirical

                
Ưu điểm: Tốt nhất qua thực nghiệm, rất hiệu quả

                
Nhược điểm: Không có công thức rõ ràng, phải lưu trữ dãy

                

                    💡 Marcin Ciura tìm ra sequence này qua thử nghiệm thực tế trên hàng triệu test case!

💻 Code mẫu Shell Sort


            
C++

            

                
#include <iostream>
#include <vector>
using namespace std;

void shellSort(vector<int>& arr) {
    int n = arr.size();

    // Bắt đầu với gap lớn, giảm dần
    for (int gap = n/2; gap > 0; gap /= 2) {
        // Thực hiện insertion sort với gap hiện tại
        for (int i = gap; i < n; i++) {
            int temp = arr[i];
            int j = i;

            // Dịch chuyển các phần tử đã sắp xếp
            while (j >= gap && arr[j - gap] > temp) {
                arr[j] = arr[j - gap];
                j -= gap;
            }

            arr[j] = temp;
        }
    }
}

int main() {
    vector<int> arr = {64, 34, 25, 12, 22, 11, 90};

    cout << "Mảng ban đầu: ";
    for (int x : arr) cout << x << " ";
    cout << endl;

    shellSort(arr);

    cout << "Mảng sau khi sắp xếp: ";
    for (int x : arr) cout << x << " ";
    cout << endl;

    return 0;
}

def shell_sort(arr):
    n = len(arr)
    gap = n // 2

    # Giảm gap cho đến 0
    while gap > 0:
        # Insertion sort với gap hiện tại
        for i in range(gap, n):
            temp = arr[i]
            j = i

            # Dịch chuyển các phần tử đã sắp xếp
            while j >= gap and arr[j - gap] > temp:
                arr[j] = arr[j - gap]
                j -= gap

            arr[j] = temp

        gap //= 2

    return arr

JavaScript

            

                
function shellSort(arr) {
    const n = arr.length;
    let gap = Math.floor(n / 2);

    // Giảm gap cho đến 0
    while (gap > 0) {
        // Insertion sort với gap hiện tại
        for (let i = gap; i < n; i++) {
            const temp = arr[i];
            let j = i;

            // Dịch chuyển các phần tử đã sắp xếp
            while (j >= gap && arr[j - gap] > temp) {
                arr[j] = arr[j - gap];
                j -= gap;
            }

            arr[j] = temp;
        }

        gap = Math.floor(gap / 2);
    }

    return arr;
}

            for (int i = gap; i < n; i++) {
                int temp = arr[i];
                int j = i;

                arr[j] = temp;
            }
        }
    }

💡 Lưu ý khi implement

            
    
                
  • Gap sequence: Code trên dùng Shell's original (n/2). Để tối ưu hơn, hãy dùng Knuth
                    hoặc Ciura sequence
    • 
                
  • In-place: Tất cả các implementation trên đều sắp xếp tại chỗ, không cần bộ nhớ phụ
                
    • 
                
  • Stable: Shell Sort không phải stable sort, thứ tự tương đối của các phần tử bằng
                    nhau có thể thay đổi
    • 
                
  • Performance: Shell Sort hiệu quả với mảng kích thước vừa (< 10,000 phần tử)
    •

Ưu điểm

            
    
                
  • In-place sorting - Không cần bộ nhớ phụ
    •

    • 
                
  • Không tối ưu với mảng rất lớn
    • 
                
  • Khó phân tích độ phức tạp chính xác

🎯 Khi nào nên dùng Shell Sort?

            

                
✅ Nên dùng khi:

                
    
                    
  • Mảng có kích thước vừa phải (1,000 - 10,000 phần tử)
    • 
                    
  • Giới hạn bộ nhớ (cần in-place sorting)
    • 
                    
  • Muốn code đơn giản, dễ debug
    • 
                    
  • Dữ liệu gần như đã sắp xếp
    • 
                    
  • Không yêu cầu stable sort
    • 
                    
  • Cần thuật toán dễ implement hơn Quick Sort hoặc Merge Sort
    • 
                

            


            

                
❌ Không nên dùng khi:

                
    
                    
  • Mảng rất lớn (> 100,000 phần tử) → Dùng Quick Sort hoặc Merge Sort
    • 
                    
  • Cần stable sort → Dùng Merge Sort
    • 
                    
  • Cần worst case O(n log n) đảm bảo → Dùng Heap Sort
    • 
                    
  • Dữ liệu hoàn toàn ngẫu nhiên và lớn → Quick Sort thường tốt hơn
    • 
                    
  • Cần performance tuyệt đối → Dùng thư viện sorting có sẵn (std::sort, Arrays.sort, ...)
    •
